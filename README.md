# TradeLoop — Commodity Trade Lifecycle (CTRM) Engine

A compact commodity trading and risk management system covering the full trade lifecycle for
German power, TTF gas and Brent crude, as physical forwards and fixed-for-floating swaps:

**capture → validate → confirm → positions, MtM and VaR → settle → reconcile → report**

Built to learn how ETRM/CTRM platforms are structured and how their front, middle and back office
functions connect.

## What it does

| Area | Module | Highlights |
|---|---|---|
| Trade capture | `trades.py` | 7 validation rules (VR-01 to VR-07) incl. a fat-finger check against the strip forward curve; lifecycle state machine; full version history and audit log in SQLite |
| Confirmations | `confirmations.py` | Reads free-text counterparty confirmations in 3 layouts, extracts 8 economic fields, auto-confirms on full match, otherwise names the mismatched fields |
| Market and credit risk | `risk.py` | Positions by book/commodity/month, discounted MtM in USD, daily P&L explain, 1-day historical VaR (95/99%), credit exposure vs limits |
| Settlement | `settlement.py` | Physical invoices, swap cash settlement against monthly average index, netting, reconciliation with 5 break types |
| Regulatory reporting | `reporting.py` | REMIT-style transaction report (N/M/C) with a stable UTI and field checks |
| API | `api.py` | FastAPI REST endpoints for all of the above |

**Testing:** 122 pytest tests (`pytest`) and a 24-case UAT pack traced to 14 requirements
(`python scripts/run_uat.py` → `results/uat_results.md`). CI runs both on every push.

**Read this before quoting the numbers:** the market data, confirmation documents and counterparty
statements are synthetic and generated by this repo. The results show the logic is consistent end
to end; they are not accuracy figures on real counterparty paperwork.

## Run it

```bash
pip install -r requirements.txt
python -m tradeloop.scenario          # end-to-end run, writes results/
python scripts/run_uat.py             # UAT pack
pytest -q                             # unit and integration tests
uvicorn tradeloop.api:app --reload    # API, docs at http://127.0.0.1:8000/docs
```
